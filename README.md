# Ghana School Portal

Production-oriented Ghana Primary (P1-P6) and Junior High School (JHS 1-3) management portal.

This repository is being built from the supplied school portal specification with Phase 1 prioritized for production readiness.

## Phase 1 scope

- Role-based school administration
- Teacher access control
- Parent/student result visibility rules
- Audit logging
- P1-P6 and JHS 1-3 class structures
- Student onboarding and automatic admission numbers
- Boarder/day student tracking
- 30% class score + 70% examination score
- Score submission locking and Headmaster unlock
- Broadsheet and result publication foundation
- Fee categories and class fee assignments
- Payment recording and receipt references
- Result blocking for outstanding fees
- Bulk SMS foundation
- Headmaster dashboard foundation

Further Phase 2 and Phase 3 modules will extend this architecture without rebuilding Phase 1.
